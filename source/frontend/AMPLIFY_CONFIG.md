# AWS Amplify Configuration Guide

## Overview

This document explains how the AWS Amplify configuration is set up for the Retail Pricing Agent Orchestrator frontend application, including Cognito User Pool authentication.

## Configuration Files

### Primary Configuration: `src/amplify-config.ts`

The main configuration file that handles:
- AWS Cognito User Pool setup
- GraphQL API configuration
- Environment-specific settings

### Amplify Outputs: `amplify_outputs.json`

Standard Amplify configuration file generated by CDK or Amplify CLI containing:
- Cognito User Pool details
- GraphQL API endpoints
- Authentication settings

## Configuration Sources

The configuration system supports multiple sources in order of priority:

1. **amplify_outputs.json** (Primary) - Generated by CDK deployment
2. **Environment Variables** (Fallback) - For custom deployments

### Environment Variables

Create a `.env.local` file in the frontend directory for local development:

```bash
# AWS Cognito Configuration
VITE_AWS_REGION=us-west-2
VITE_USER_POOL_ID=us-west-2_xxxxxxxxx
VITE_USER_POOL_CLIENT_ID=xxxxxxxxxxxxxxxxxxxxxxxxxx
VITE_IDENTITY_POOL_ID=us-west-2:xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

# GraphQL API Configuration
VITE_GRAPHQL_ENDPOINT=https://your-appsync-endpoint.appsync-api.us-west-2.amazonaws.com/graphql
VITE_GRAPHQL_API_KEY=your-api-key-here
```

## Usage

### Automatic Initialization

Amplify is automatically configured when the application starts in `main.tsx`:

```typescript
import { configureAmplify } from './amplify-config';

// Configure AWS Amplify before rendering the app
try {
  configureAmplify();
} catch (error) {
  console.error('Failed to configure Amplify:', error);
}
```

### Manual Configuration Check

You can verify the configuration programmatically:

```typescript
import { getAmplifyConfigInfo } from './amplify-config';

// Get configuration information
const configInfo = getAmplifyConfigInfo();
console.log('Config:', configInfo);
```

## Authentication Modes

### Standard Cognito Authentication

Default authentication using AWS Cognito User Pools:
- Email/password sign-up and sign-in
- Password reset functionality
- Multi-factor authentication (if enabled)
- Session management

## Configuration Validation

The system validates configuration on startup and will:
- Log configuration details (excluding sensitive data)
- Throw errors for missing required settings
- Provide helpful error messages for troubleshooting

### Required Configuration

Minimum required settings:
- `region`: AWS region (e.g., 'us-west-2')
- `userPoolId`: Cognito User Pool ID
- `userPoolWebClientId`: Cognito User Pool Client ID

### Optional Configuration

- `identityPoolId`: For AWS service access with temporary credentials
- `graphql.endpoint`: AppSync GraphQL API endpoint
- `graphql.apiKey`: API key for GraphQL (if using API_KEY auth)

## Troubleshooting

### Common Issues

1. **Missing Configuration Error**
   ```
   Error: Missing required Cognito configuration
   ```
   - Check that `amplify_outputs.json` exists and contains auth configuration
   - Verify environment variables are set correctly

2. **GraphQL API Issues**
   - Check that the GraphQL endpoint is accessible
   - Verify API key is valid (if using API_KEY authentication)
   - Ensure the region matches the API deployment region

### Debug Information

Enable debug logging by checking the browser console for:
- Configuration details on startup
- Authentication state changes
- API call results

### Verification Script

Run the verification script to test configuration:

```typescript
import { verifyAmplifyConfig } from './verify-amplify';

verifyAmplifyConfig(); // Returns true if successful
```

## Security Considerations

- API keys and sensitive configuration are not logged
- Environment variables should not be committed to version control
- Use `.env.local` for local development secrets
- Production configuration should use AWS Systems Manager Parameter Store or similar

## Integration with Components

The configuration automatically integrates with:
- `@aws-amplify/ui-react` components
- Custom authentication hooks
- GraphQL API clients
- Session management utilities

No additional setup is required in individual components once Amplify is configured in `main.tsx`.
